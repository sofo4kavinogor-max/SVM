# СРС2. Численные методы решения нелинейных уравнений

**Выполнили:** Сергеева С.Д., Аникина У.О. (МЗО-236БВ-25)

## Задача
Решить уравнение `cos(x) - x = 0` на `[0, 1]` с точностью `10⁻³` и `10⁻⁵`.

## Реализованные методы
- Метод бисекции
- Метод хорд
- Метод Ньютона
- Метод простых итераций

## Файлы
- `bisec.py` — код программы
- `README.md` — описание

## Результаты
| Метод | 10⁻³ | 10⁻⁵ |
|---|---|---|
| Бисекция | 9 итер. | 16 итер. |
| Хорды | 3 итер. | 4 итер. |
| Ньютон | 2 итер. | 3 итер. |
| Простые итерации | 15 итер. | 27 итер. |

Корень: `x* ≈ 0.739085133`
